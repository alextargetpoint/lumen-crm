Фоновое приложение на маке брокера пишет и расшифровывает звонки локально. Транскрипт и квалификация падают прямо в карточку лида. Клиент ничего не видит — Zoom и Google Meet не включают запись, бот в звонок не заходит.

Как это работает

Запись без плашки, разбор без рук

Нативная запись Zoom показывает клиенту «идёт запись» — это убивает доверие на продажах. Здесь звук берётся локально с машины брокера через системный API macOS, Zoom/Meet не трогаются.

Любой созвон

Zoom, Google Meet, Microsoft Teams и даже обычный телефонный звонок на громкой — ловит всё.

Сам ловит и матчит

Висит в менюбаре, определяет старт/конец звонка и привязывает его к нужному лиду по вашему расписанию встреч.

Транскрипт + квалы

После звонка расшифровка, ИИ-резюме и поля карточки (цель, бюджет, сроки, объект) заполняются сами.

Клиент не видит

Никакой плашки записи, никакого бота в звонке. Звук пишется только у вас на машине.

Windows

А на Windows?

Нативное приложение для Windows в работе — появится здесь же. Пока два рабочих пути:

Кросс-платформенный скрипт

Python 3 + ffmpeg + виртуальный аудио-кабель (VB-Audio Cable) для системного звука. Транскрипт так же падает в карточку. Скрипт и инструкция — у администратора агентства.

Без установки — вручную

После звонка откройте карточку лида → кнопка «Запись» → загрузите аудио/видео разговора. Оно само расшифруется и разложится по полям.

Важно

Что видит клиент и про согласие

Клиент не видит ничего. Zoom/Meet/Teams не включают запись, бот в звонок не заходит, плашки «идёт запись» нет. Звук берётся локально с вашего мака.
Про согласие. Запись разговора во многих юрисдикциях (EU/GDPR) требует согласия собеседника. Безопасный способ без плашки во время звонка — зашить в подтверждение встречи фразу «звонки могут записываться для повышения качества сервиса». Этого достаточно, и клиент во время разговора ничего не видит.
Если что-то не так

Частые вопросы

macOS пишет «Программу нельзя открыть, разработчик не проверен»

Это Gatekeeper. Нажмите по иконке приложения правой кнопкой → «Открыть» и подтвердите. Нужно только при самом первом запуске.

Записался только мой голос, клиента не слышно

Не выдан доступ «Запись экрана» (это системный звук). Включите его в Системные настройки → Конфиденциальность → Запись экрана для Lumen Notetaker и перезапустите приложение.

Звонок не привязался к нужному лиду

Приложение матчит звонок по вашему расписанию встреч. Если встречи в календаре не было — откройте карточку лида и загрузите запись вручную (кнопка «Запись» в карточке), либо создайте встречу заранее.

Не нужен ли ffmpeg или BlackHole?

Нет. Приложение использует системный API macOS (ScreenCaptureKit) — никаких дополнительных программ ставить не надо.
