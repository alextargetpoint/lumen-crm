Готовность к выкату
Правило выката (SaaS-дисциплина): обновление НЕ уходит в прод, пока гейт не «PASS».
Процесс: 1. правки локально → 2. node test/release-gate.mjs "что меняли" (изоляция+антивзлом) → 3. локальная проверка в браузере → 4. при PASS — git push (Railway выкатит) → 5. сверить версию на проде. Полный регламент — docs/RELEASE-PROCESS.md.
