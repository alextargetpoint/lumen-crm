## 1. Дорожная карта тестирования (4 этапа)

### Этап A — «полный прогон на тестовом номере Meta» (1–2 дня, $0)

Цель: вся петля «лид → ИИ-диалог → квалификация → передача» на НАСТОЯЩЕМ
WhatsApp, но с тестовым номером Meta (бесплатный, до 5 получателей).

🧍 Твои шаги (30–40 минут, по порядку):
1. Зайди на https://developers.facebook.com → **My Apps → Create App** → тип **Business**.
2. В приложении: **Add Product → WhatsApp → Set up**. Привяжи (или создай) Business Portfolio.
3. Откроется **API Setup**: там уже есть **тестовый номер** (Test number). Скопируй мне три вещи:
   - `Phone number ID`
   - `WhatsApp Business Account ID` (WABA ID)
   - `Temporary access token` (живёт 24ч — для этапа A хватит; постоянный сделаем на этапе B)
4. Там же **Manage phone number list → добавь свой личный номер** как получателя (придёт код подтверждения в WA).
5. Всё. Дальше моё.

🤖 Мои шаги:
1. Подниму **стабильный URL** для вебхука (named cloudflare tunnel или сразу тест-инстанс на Railway — см. этап C).
2. В Meta App → WhatsApp → Configuration пропишу Callback URL `https://<url>/wa/webhook`, verify token `lumen-verify`, подписку на `messages`.
3. В Lumen «Подключения» переключу mock → cloud, вобью phoneId/WABA/token.
4. Прогон: пишешь со своего личного WA на тестовый номер → ИИ отвечает → квалификация 4/4 → передача брокеру → подборка → трекинг просмотра. Плюс цепочка касаний на ускоренном демо-времени.

### Этап B — «боевой номер + верификация» (3–7 дней, ~$5–15)

Цель: настоящий номер, постоянный токен, шаблоны — то, что нужно каждому агентству.

🧍 Твои шаги:
1. **Верификация бизнеса** в Meta Business Manager (Business Portfolio → Settings → Business verification): загрузить документы юрлица (регистрация компании, адрес, сайт/домен с корпоративной почтой). Обычно 1–5 дней. Без неё лимит 250 исходящих диалогов/сутки — для теста хватит, для 500 лидов нет.
2. **Номер телефона** для WhatsApp. Требования: номер, на котором НЕТ обычного WhatsApp (или готов его потерять), и который может принять SMS/звонок с кодом. Варианты:
   - виртуальный номер (Zadarma/DID-провайдер, ~$2–7/мес) — принимает звонок с кодом, ок;
   - свежая SIM.
   ⚠️ Номер агентства, на котором живёт их обычный WhatsApp Business app, переносить НЕ надо — при переносе в Cloud API телефонное приложение отвязывается. Для агентств берём НОВЫЙ номер («номер отдела продаж»).
3. **Постоянный токен**: Business Settings → Users → System Users → создать system user (admin) → Add Assets (приложение + WABA) → Generate Token (`whatsapp_business_messaging`, `whatsapp_business_management`, без срока). Скопируй мне.
4. **Платёжка**: WhatsApp Manager → Payment settings → привязать карту (шаблонные сообщения платные, списывает Meta).

🤖 Мои шаги:
1. Регистрирую номер в Cloud API, display name.
2. Сабмичу **шаблоны** (первое касание, шаги цепочки, реанимация) на модерацию Meta — постараюсь провести цепочки как *utility*, это в 3–4 раза дешевле *marketing* (решает модерация Meta).
3. Полный боевой прогон уже на реальном номере.

### Этап C — «переезд с Mac на Railway» (полдня, ~$5/мес за инстанс)

Mac+туннель — ок для разработки, но боевой вебхук Meta обязан жить на стабильном URL 24/7.
План: 1 агентство = 1 Railway-сервис (у Lumen один tenant на инстанс — это норм: изоляция данных, бан-риска и биллинга по клиентам).

🤖 Всё делаю я: репо на GitHub (private) → Railway service → volume для `data/db.json` → env-ключи → домен `<agency>.lumen.…` → перенос вебхука. От тебя: 🧍 доступ к Railway-аккаунту (он уже есть — там крутятся сервисы TargetPoint).

### Этап D — «дополнительные каналы» (по мере надобности)

- **Телефония**: v1 = ручная загрузка записей (уже работает: карточка → «Звонок» → Whisper). v2 = Zadarma: аккаунт → номер/SIP-транк → включить запись звонков → вебхук на `/hooks/call` → транскрипты сами падают в карточку. Для Дубая местные номера через DID-провайдеров ОАЭ дорого и бюрократично — большинству агентств хватит записей из их телефонии + Zoom.
- **ElevenLabs** (голосовые в цепочках): 🧍 аккаунт elevenlabs.io, тариф Creator $22/мес, склонировать голос брокера (3–5 мин чистой записи) → ключ+voiceId мне → вбиваю в «Подключения», тест-кнопка уже в UI.
- **Лидоген-мост**: из Meta Lead Ads → Albato/направляю вебхук на `/hooks/lead` (секрет + маппинг полей уже готовы). Тест — сабмит тестового лида из Ads Manager.
- **Отчёты в Telegram**: бот уже поддержан в коде — нужен botToken + chat_id, вбиваем в настройки, тест-кнопка есть.

## 2. Расходники на 1 агентство при 500 лидов/мес

Допущения: 500 входящих лидов, ~60% вступают в диалог (диалоги с клиентом
бесплатны у Meta в 24ч-окне), молчунам уходит цепочка 5–7 касаний шаблонами,
реанимация базы ~500 сообщений/мес, ~100 звонков по 15 мин на транскрибацию,
~300 голосовых по 30 сек.

| Статья | Расчёт | $/мес |
|---|---|---|
| WhatsApp шаблоны (Meta) | ~2 000–2 500 шаблонных сообщ. × $0.011 (utility, ОАЭ) … $0.05 (marketing) | **$25–115** |
| LLM-диалоги (gemini-2.5-flash-lite $0.10/$0.40 за 1М) | ~500 диалогов × ~30k in / 3k out | **$3–8** |
| Транскрибация (Whisper $0.006/мин) | ~1 500 мин | **$9–15** |
| Голосовые (ElevenLabs Creator) | ~150 мин TTS | **$22–30** |
| Хостинг (Railway, 1 инстанс) | | **$5–8** |
| Виртуальный номер под WA | | **$2–7** |
| Телефония Zadarma (опция) | номер + запись | $5–20 |
| **ИТОГО** | | **≈ $70–180, планово ~$120** |

Выводы для оффера:
- Главная переменная — **тип шаблона WhatsApp**: utility vs marketing = разница в 4 раза. Тексты цепочек пишем под utility-модерацию.
- ИИ — копейки: даже ×3 запас — $10. Бояться токенов не надо.
- Cost-safe дефолты уже в продукте: LLM «auto» не жжёт токены на симуляциях, safe mode кампаний ограничивает пачки.

### Рамка оффера (10 агентств)

- **Сетап, 1-й месяц: $1 500–2 500** (WABA+верификация, номер, цепочки под гео агентства, критерии квалификации, импорт базы, обучение брокеров).
- **Поддержка: $500–790/мес**, «всё включено» до 500 лидов/мес (расходники ~$120 → маржа 75%+). Свыше 500 лидов — ступень +$200/мес за каждые +500.
- 10 агентств на поддержке = $5 000–7 900 MRR при ~$1 200 расходников.

## 3. Онбординг одного агентства — чеклист

День 0 — собрать с агентства:
- [ ] документы юрлица для верификации Meta (или верифицируем на НАШЕ юрлицо и ведём WABA как сервис — быстрее, но номер юридически «наш»; выбрать модель!)
- [ ] логотип, название, «об агентстве», подпись менеджера (профиль в Lumen)
- [ ] гео-направления (Дубай/Бали/…) → пороги бюджета и критерии квалификации
- [ ] база спящих лидов (CSV/выгрузка из их CRM) для реанимации
- [ ] источники лидов (какой лидген, куда сейчас падают заявки)
- [ ] брокеры: имена, смены, телефоны (автораспределение)

День 1 (🤖 + 🧍 15 мин):
- [ ] Railway-инстанс `<agency>` + домен + ключи
- [ ] Meta Business агентства: app + WABA, номер, вебхук (по шагам этапов A–B)
- [ ] запущена верификация бизнеса

День 2–5:
- [ ] шаблоны на модерации → одобрены
- [ ] цепочки и критерии настроены под гео агентства
- [ ] мост лидгена подключён, тестовый лид прошёл всю петлю
- [ ] импорт спящей базы, скоринг, первая реанимационная кампания в safe mode
- [ ] отчёты в Telegram-чат агентства

День 5–7 — приёмка:
- [ ] живой лид с рекламы прошёл: касание ≤1 мин → диалог → квал → передача брокеру с саммари
- [ ] обучение: 30-мин созвон с брокерами (перехват у ИИ, карточка, подборки)
- [ ] включён автопилот, договорён недельный чек-ин
