# Lumen — AI-CRM для агентств недвижимости

Вертикальная CRM с ИИ-первой линией квалификации, цепочками касаний и реанимацией спящей базы. Канал — WhatsApp (официальный Cloud API + вебхук входящих).

## Запуск

```bash
node server/index.js   # → http://localhost:5077
```

Zero-dependency (Node 18+). Данные — `data/db.json` (пересоздаётся из seed при удалении).

## Что внутри

| Раздел | Что делает |
|---|---|
| Обзор | KPI, воронка, живая лента событий, «человек vs ИИ» |
| Воронка | Канбан по стадиям (new → touch → dialog → qualified → handover → viewing → deal / sleeping / lost) |
| Диалоги | WhatsApp-инбокс: чат, панель квалификации (4 оси с цитатами), саммари, передача брокеру, перехват у ИИ |
| ИИ-квалификатор | Автопилот, критерии по гео (порог бюджета, down-sell, регламент), стоп-слова |
| Цепочки касаний | 7 касаний / 18 дней для молчунов, вкл/выкл шагов; работает только до первого ответа клиента |
| Реанимация базы | Скоринг спящих (свежесть+вовлечённость+lastDir+прошлый score), сегменты A/B/C, кампании с safe mode (пачки, паузы, окно по поясу клиента) |
| Номера | Пул номеров: качество, лимиты/сутки, тиры, прогрев, карантин |
| Шаблоны | Utility/Marketing + статус модерации Meta |
| Аналитика | «Человек против ИИ», конверсия по гео, канал |
| Подключения | WhatsApp Cloud API (phoneId/WABA/token, webhook `/wa/webhook`), демо-режим |

## Архитектура

- `server/index.js` — HTTP-сервер (node:http), REST API, вебхук Cloud API (GET verify + POST входящие).
- `server/ai.js` — квалификатор: факты 4 осей извлекаются ТОЛЬКО из входящих сообщений клиента (регэксп-ядро v1, LLM-слой подключается поверх без смены логики), стоп-слова, саммари для брокера.
- `server/engine.js` — единая точка отправки `send()` (сюда встраивается боевой Cloud API), цепочки касаний, кампании реанимации, здоровье номеров, демо-симулятор ответов.
- `server/store.js` — JSON-персистентность (меняется на Firebase/Postgres в одном модуле).
- `public/` — SPA без сборки: светлая рабочая зона + тёмно-синий сайдбар/hero-панели, стекло дозированно (модалки/тосты). Логотип — `logo.svg` (4-лучевая искра).

## Демо-режим

`Подключения → Демо`: ускорение времени (1 «день» цепочки = 90 сек) и симуляция ответов клиентов — вся петля «заявка → касание → диалог → квалификация → передача брокеру» видна вживую. Сброс демо-данных там же.
