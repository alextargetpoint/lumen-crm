## ✅ Уже сделано (сентябрь, проверено)

**Ядро SaaS**
- Мультиарендность: публичная регистрация, изоляция тенантов (ALS + per-tenant db.json + registry), сессии. Тест saas-auth 83/83.
- Безопасность: scrypt-пароли, rate-limit, антипентест 34/34, **детектор аномалий** (401/403-скан, брутфорс админ-ключа, чужой TG-secret, экспорт/удаление) + вкладка «🛡 Безопасность» в админке основателя + алерт в Telegram.
- Бэкапы: авто + PRE-WIPE + авто-восстановление из повреждённого db.json; PRE-IMPORT/PRE-DELETE снимки.
- GDPR: privacy/terms/dpa/cookies/data-deletion (единый бежевый стиль, Brussels), consent при регистрации, экспорт данных, удаление аккаунта.
- Админка основателя `/admin.html`: аккаунты/тарифы/suspend/delete/impersonate/рассылки/журнал/**безопасность**.

**Каналы связи**
- Telegram: **мультиарендный** — вебхук роутит по secret_token, мини-апп по токену, изоляция подтверждена. Мост TG⇄WA (брокер отвечает из личного TG).
- WhatsApp «серый» (Baileys/QR через облачный воркер на Railway): подключение номеров по QR, прогрев, мультитенант `tid__phone`. **Лимит номеров по тарифу** (Base=3) + гайд «свои номера по QR».
- WhatsApp «белый» (Cloud API, `server/wa.js`): слой отправки/приёма + шаблоны написан. НЕ подключён к боевому номеру (нужен Embedded Signup, см. ниже).

**Продукт**
- Мастер миграции из amoCRM/Bitrix24/HubSpot/Excel (робастный CSV + маппинг + дедуп + PRE-IMPORT бэкап).
- Настройки: пересобранная IA (6 секций), премиум-индикатор смены темы, контраст по пресетам.
- Живая диктовка (Web Speech, текст сразу по мере речи) — везде.
- Встречи: страница `/m/:id` с подтверждением участия/переносом + **авто-Jitsi-ссылка** для видео (без OAuth).

## 🎯 План действий (что осталось, по блокам)

### 1. Facebook / Meta (для «белого» WhatsApp и рекламы)
- 🧍 **Стать Meta Tech Provider / Solution Partner** (Business Manager → заявка). Без этого нет Embedded Signup.
- 🧍 **App Review** приложения Meta для продукта WhatsApp (permissions: whatsapp_business_management, whatsapp_business_messaging). Инструкция-аналог: `docs/META-ADS-APP-REVIEW.md`, `docs/WHATSAPP-META-PLAYBOOK.md`.
- 🧍 Боевой публичный домен для вебхука (уже есть `app.lumen247.com` — годится, в отличие от trycloudflare).
- 🤖 **Embedded Signup попап** в дашборде: кнопка «Подключить WhatsApp» → FB-логин → выбор/создание WABA → номер → OTP → авто-заполнение `settings.wa` (phone_number_id, waba_id, токен). Событие `onWhatsAppEmbeddedSignup` → сохранить в конфиг тенанта.
- 🤖 Верификация подписи входящих вебхуков (app secret) — уже есть поле; проверить на боевом.

### 2. WhatsApp (обе стратегии)
- ✅ Серый (QR) — работает; Base=3 своих номера + прогрев + инструкция.
- 🤖 **Белый (Cloud API)**: докрутить после статуса Tech Provider — Embedded Signup → авто-конфиг → «белая рассылка» шаблонами (шаблоны уже создаются). Выбор источника номера (Twilio-sender / купленный / чистый).
- 🤖 Связать статус прогрева (браузерный коллектор на Mac) с дашбордом: кнопка «на прогрев» у номера + статус «готов к рассылке».
- ⚠️ Инвариант: номер НЕ должен быть одновременно в неофициальном web-клиенте (серый) и в Cloud API (белый) — Meta банит. Развести в UI.

### 3. Телефония — переписка с саппортом Twilio (🧍 + 🤖 подготовка)
- 🧍 **Тикет в Twilio**: (а) почему снесли схему / что нужно для регистрации; (б) A2P/регуляторка для номеров ЕС/ОАЭ; (в) WhatsApp Sender через Twilio-BSP (путь A блюпринта) — возможен ли на субаккаунтах.
- 🤖 Подготовить текст тикета + список вопросов (могу написать).
- Решение: **Twilio vs Telnyx** (Telnyx часто проще с номерами ЕС/ОАЭ и дешевле). Сравнение — в чате уже давал; зафиксировать выбор.
- 🤖 После решения: субаккаунт на тенанта (`POST /Accounts.json`), UI «Подключения → Телефония» (ключи + «Проверить»), раздел «Номера».

### 4. Автоматическая покупка номеров
- ✅ API поиска/покупки есть (`/api/telephony/numbers/search|buy`) — под Twilio.
- 🤖 **UI «Номера»**: единый экран — выбрать цель (звонки / WhatsApp-белый / прогрев) → страна/тип → поиск → купить в 1 клик → номер падает в нужный пул (гео caller-ID / WA-sender / очередь прогрева).
- 🤖 Гео caller-ID подбор по стране клиента (`pickCallerId`) — есть, проверить на боевых номерах.
- ⚠️ Не любой VoIP годится для WhatsApp (Meta режет) — для белого брать Twilio-sender или чистый; для серого/звонков — обычный DID.

### 5. eSIM-сервис (для «своих» номеров на Base) — НОВОЕ
- Проблема: на Base агентство заводит свои номера само (Android-клон / iPhone 2 акка + Business), но им нужны **SIM/eSIM нужных стран**, принимающие SMS для регистрации WhatsApp.
- 🧍 Выбрать eSIM-провайдера с API (кандидаты: **Airalo Partner API**, **eSIM-Go**, **Maya.net**) — нужен аккаунт/договор.
- ⚠️ Критично: не любой eSIM принимает A2P-SMS для регистрации WA (многие data-only). Проверить, что провайдер даёт номер с приёмом SMS. Иначе eSIM годится только для интернета, не для регистрации WA.
- 🤖 После выбора: раздел «Купить eSIM» в дашборде (страна → тариф → купить → QR-профиль eSIM + номер) + инструкция «установить eSIM → зарегистрировать WhatsApp → подключить к Lumen по QR».
- Монетизация: eSIM = расходник с наценкой (как номера/минуты).

### 6. Внешние клиентские страницы (встречи/приглашения) — задача A от 14.09
- Сейчас: `/m/:id` работает (Jitsi-ссылка + подтверждение/перенос), но статичная по стилю.
- 🤖 **Тематизация под все пресеты** (крем/стекло/бордо/…): страница должна наследовать тему агентства, быть динамичной/красивой.
- 🤖 **Активная кнопка «Участвовать»** сразу на приглашении (для видео — Jitsi-ссылка уже есть; сделать её главным CTA).
- 🤖 Опция **Google Meet** вместо Jitsi: требует OAuth Google Calendar на агентство (создание события с conferenceData → Meet-ссылка). Jitsi — дефолт без OAuth; Meet — для тех, кто подключил Google. 🧍 нужен Google Cloud проект + OAuth consent.

## Тарифная градация (по факту схемы)
- **Base**: серый WhatsApp (свои номера по QR, до 3, прогрев, инструкция), свой TG-бот. Без покупки через нас, без белой рассылки, без телефонии.
- **Pro**: + белый WhatsApp (Cloud API/Embedded Signup), покупка номеров/eSIM в дашборде, больше номеров, телефония опц.
- **Enterprise**: + субаккаунт Twilio, пул номеров по странам, приоритетный прогрев, white-label/домен/SSO, setup-fee.
- Номера/минуты/eSIM/WA-разговоры = метрируемые расходники (квота в плане, сверх — по прайсу). Fair-use лимиты — в оферте.
