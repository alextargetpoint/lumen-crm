# Обучение ИИ: дефолт (вшит) + кастомизация под каждое агентство

## Сейчас (дефолт — вшит в мозг ИИ)
Академия продаж = `server/academy.js` (`academy_data.json`: 205 роликов → 953 приёма) + `server/playbook.js`.
Впрыск в ИИ идёт в `server/llm.js`:
- `academy.forObjection(текст)` — банк возражений: если последнее сообщение клиента похоже на возражение,
  в промпт добавляется эталонный ответ.
- `academy.methodologyRef()` — дистиллят методологии (для оценки звонка/подсказок).
- `playbook.forContext(lead, N)` — 2–3 приёма под текущий момент сделки.

Это и есть «дефолтная составляющая CRM для агентств недвижимости» — работает у всех, страницу «Академия»
можно скрыть (сделано: `DEFAULT_HIDDEN_PAGES`), т.к. знание живёт в ИИ, а не как раздел.

## Что нужно (SaaS-кастомизация ИИ под агентство)
Каждое агентство может иметь своё видение продаж → нужна возможность **дообучать/переопределять** ИИ,
не ломая дефолт. Слоистая модель (по возрастанию приоритета):

```
[1] Базовый дефолт (вшит)      — academy_data.json + playbook.js (для всех)
[2] Кастом агентства (per-tenant) — db.settings.ai.training: {...}
[3] Пер-гео / пер-проект (опц.)  — переопределения под рынок/ЖК
```

### Хранение (per-tenant, `db.settings.ai.training`)
```js
training: {
  vision: "",        // как МЫ продаём: тон, ценности, чего НЕ делаем (свободный текст, до ~4000)
  scripts: [],       // свои эталонные ответы: [{trigger, answer}] — дополняют банк возражений
  facts: [],         // факты об агентстве/продукте, которые ИИ должен знать/утверждать
  forbidden: [],     // стоп-темы/фразы (комплаенс)
  tone: "",          // короткая инструкция тона (напр. «премиум, без давления»)
  overrideDefault: false // false = дополняем вшитое; true = кастом важнее в конфликте
}
```

### Впрыск (минимальная правка llm.js)
В сборке системного промпта добавить блок ПОСЛЕ дефолтной методологии:
```
--- Стиль и знания агентства (приоритет над общими приёмами при конфликте, если overrideDefault) ---
{vision}
Тон: {tone}
Факты (утверждать как истину): {facts}
Никогда: {forbidden}
Эталонные ответы: {scripts как пары триггер→ответ}
```
`forObjection()` — сначала искать совпадение в `training.scripts`, затем в дефолтном банке.

### Где редактировать (UI)
Раздел «Автоматизация → ИИ-квалификатор» или Настройки → ИИ: форма «Обучение ИИ» с полями vision/tone/
facts/forbidden/scripts + тумблер «кастом важнее дефолта». Плюс кнопка **«Проверить на примере»** —
прогнать тестовое сообщение клиента и показать, как ИИ ответит с учётом кастома (быстрый цикл проверки).

### Варианты обучения (то, что просил — «ишка обучается в разных вариациях»)
- **A/B тон**: два профиля тона → сравнить конверсию.
- **Импорт своей методички**: агентство грузит PDF/текст своих скриптов → ИИ-дистилляция в `scripts/facts`
  (как academy.js делает из роликов, но per-tenant).
- **Обучение на своих диалогах**: взять выигранные сделки агентства → извлечь удачные формулировки в
  `scripts` (с согласия, приватно на тенант).

### Приватность
`training` — строго per-tenant (ALS-изоляция, как весь db). Данные одного агентства НИКОГДА не попадают в
промпт другого. Импортированные методички/диалоги не уходят в общий дефолт.
